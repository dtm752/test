# АйДа Белорецк! — тестовая статическая версия для GitHub Pages

Адаптивный сайт-каталог на HTML, CSS, JavaScript и JSON. В этой версии **нет форм, отправки заявок или сбора персональных данных**. Посетители могут только открыть указанные владельцем контакты: e-mail, телефон, Telegram, VK и MAX.

## Публикация на GitHub Pages

1. Загрузите содержимое папки `krasivyy-beloretsk-github` в корень репозитория.
2. В GitHub откройте **Settings → Pages**, выберите публикацию из ветки `main` и папки `/ (root)`.
3. Заполните реальные контакты в `contacts.js` (см. ниже) и сделайте commit.
4. Проверьте сайт по выданному GitHub Pages адресу. Пути к CSS, JS, изображениям и страницам сделаны относительными для работы в репозитории-подкаталоге.

## Настройка контактов

Откройте `contacts.js` и заполните только подтверждённые данные:

- `email`: рабочий адрес электронной почты;
- `phone`: телефон в международном формате, например `+7...`;
- `telegram`: полная HTTPS-ссылка на официальный аккаунт или канал;
- `vk`: полная HTTPS-ссылка на официальное сообщество;
- `max`: полная HTTPS-ссылка на официальный профиль/канал MAX.

Пока поле пустое, карточка остаётся неактивной с подсказкой. Никакие контакты и реквизиты не выдуманы.

## Гастро-направление: «Эчпочмак с горячим чаем»

Это концепция, а не подтверждённый тур: башкирские домашние рецепты, эчпочмак и горячий чай на травах Белорецкого района. Перед публикацией программы нужно подтвердить меню, локацию, сезонность, происхождение и безопасную идентификацию трав, условия приготовления и продолжительность выезда. Стоимость, даты и расстояния не заявлены.

## Структура

- `index.html` — главная страница и каталог;
- `styles.css` — адаптивная стилизация;
- `script.js` — меню, каталог, карточки туров и контакты;
- `contacts.js` — контакты, заполняются владельцем;
- `data/tours.json` — 9 маршрутов/концепций;
- `assets/` — SVG-логотип, иконки, макеты;
- `pages/privacy.html`, `pages/offer.html` — правовые страницы-шаблоны.

## Важно

GitHub Pages подходит для визуального теста статического сайта, но не следует использовать его для хранения или обработки заявок с персональными данными. В этой версии формы удалены. При последующем подключении форм потребуется отдельная оценка инфраструктуры и требований 152-ФЗ. Внешние сервисы и веб-шрифты не подключаются.

Иллюстрации пейзажей и еды пока декоративные, не фотографии реальных мест и блюд. Замените их авторскими/лицензированными фотографиями Южного Урала перед публичным продвижением.


## Объединённая концепция: «АйДа Белорецк!» + «АйДа!»

В этой редакции сохранены фирменная палитра, логотип и рукописные акценты «Красивого Белорецка», а от подачи «АйДа!» добавлены ясный блок маршрута Ялангас, акцент на выборе конкретной поездки и расширенная структура направлений: горные путешествия, спортивный туризм, детские спортивные события, сплавы, авторские/гастротуры, фестивали и корпоративные выезды. Гастро-тур остаётся компактным дополнительным направлением.

В блоке Ялангаса не указаны неподтверждённые дата, цена или километраж: 1 297 м — высота вершины, а дистанция обозначена как уточняемая. До публикации следует проверить всю маршрутную информацию.
